- `lib/constants/steps.ts`: added an additive `STEP_DEFINITIONS` (+ `getStepDefinition`) export beyond spec §10's listed exports ,  a local, offline copy of the eleven steps' explanatory content (from `docs/PROJECT_PLAN.md` §6) used as a fallback in `useStepStore.fetchDefinitions()` when the backend is unreachable, which is the normal case during frontend-only development.
- Fonts: used `@fontsource/ibm-plex-sans` / `@fontsource/ibm-plex-mono` (already a dependency, no network needed) instead of `next/font/google`, since this machine has no reliable access to fetch Google Fonts at build time and CLAUDE.md forbids large/network-dependent downloads. Weight 450 (spec's `--text-ui`) isn't shipped by the font package; using weight 500 there is the nearest available fallback in `tailwind.config.ts`'s `fontSize.ui`.

Extended the existing scripts instead of adding parallel ones — the plan's own §1 spends its longest section warning against the same setting living in more than one place, and two independent setup systems would reproduce exactly that. `setup_tools.py` gained the two real gaps found (`tk`, `glpk` conda packages); `python/requirements.txt` gained the `setuptools<81`/`pandas<2.1` pins.
